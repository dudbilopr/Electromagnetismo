Guía de Uso y Diccionario de Métricas

Bienvenido a TECMD DataLab. Aquí explicamos cómo interpretar los datos generados por nuestra Inteligencia Artificial.

Score NLP (Calidad Semántica)

Este indicador evalúa la calidad estructural y semántica de un entregable (PDF/Word). Utiliza modelos de Procesamiento de Lenguaje Natural para determinar si el texto tiene coherencia, usa vocabulario académico adecuado y cumple con la extensión solicitada.

  • 8.0 - 10.0: Excelente redacción, estructura lógica fuerte.
  • 6.0 - 7.9: Aceptable, pero con oportunidades de mejora en la coherencia.
  • Menos de 6.0: Texto pobre, posible generación aleatoria o falta de profundidad.

Índice de Originalidad (Antiplagio)

Compara el texto extraído (mediante OCR) del documento del estudiante contra una base de datos interna de entregas anteriores y fuentes web (mediante APIs externas).

0-15% (Óptimo) 16-40% (Revisión Menor) >40% (Alerta de Plagio)

Flujo de Trabajo y Almacenamiento

  1. Docente/Admin: Carga la base de datos de estudiantes matriculados vía CSV.
  2. Estudiante: Ingresa y completa su perfil sociodemográfico (Estrato, región).
  3. Estudiante: Sube sus entregables a una carpeta pública de Google Drive y pega el enlace aquí.
  4. Sistema: Extrae el texto del Drive, lo pasa por el modelo NLP y guarda solo las métricas numéricas en Firebase Firestore, ahorrando un 90% en costos de base de datos.
