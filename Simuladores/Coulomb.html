Guía Rápida

  • Lápiz IA: Dibuja círculos cerrados para crear cargas. Dibuja líneas largas para crear vectores de fuerza.
  • Editar Carga: Haz clic izquierdo sobre cualquier carga para abrir su panel de propiedades (polaridad, valor, coords).
  • Mover: Selecciona la herramienta 'Selección', haz clic y arrastra cargas. Arrastra el fondo para mover el origen (X=0, Y=0).
  • Cálculo: Ajusta las unidades en el menú superior y presiona 'Calcular' para ver el desarrollo matemático.
  • Salas: Usa el Gestor de Salas para invitar amigos. Todo lo dibujado se sincroniza en tiempo real.
